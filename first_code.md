# Первый показ кода

Подготовлена структура веб-приложения, состоящего из frontend и backend. Backend создан на Python с использованием FastAPI, frontend - на React. Настроено взаимодействие частей приложения через HTTP API. Реализованы регистрация, авторизация, просмотр профиля, создание публичных и закрытых учебных комнат и присоединение к комнате по уникальному коду. Для локальной разработки используется база данных SQLite.
